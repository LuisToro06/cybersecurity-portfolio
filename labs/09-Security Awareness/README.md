# 🔐 Laboratory 09 — Security Awareness

## Awareness and Cybersecurity Education

---

## 1. Objective

The objective of this laboratory is to design, implement, evaluate, and improve a cybersecurity awareness program focused on reducing human-related security risks.

The laboratory addresses phishing awareness, password security, multifactor authentication, social engineering, secure email and web browsing, information protection, incident reporting, knowledge assessment, and continuous improvement.

---

## 2. Scope

This laboratory focuses on cybersecurity awareness and education activities within a controlled and authorized learning environment.

No real credentials, sensitive information, unauthorized phishing campaigns, malware, or credential harvesting techniques are used.

---

## 3. Methodology

The laboratory follows a lifecycle-based approach:

1. Define
2. Assess
3. Educate
4. Evaluate
5. Measure
6. Improve

---

## 4. Activities

- Activity 01 — Security Awareness Program Definition
- Activity 02 — Security Awareness Risk Assessment
- Activity 03 — Phishing Awareness
- Activity 04 — Password Security and MFA
- Activity 05 — Social Engineering Awareness
- Activity 06 — Secure Email and Web Browsing
- Activity 07 — Information Protection
- Activity 08 — Security Incident Reporting
- Activity 09 — Security Awareness Knowledge Assessment
- Activity 10 — Metrics and Continuous Improvement

---

## 5. Evidence

Evidence will be added progressively as each laboratory activity is completed.

Figure numbering and filenames will be assigned only after the corresponding evidence has been produced and validated.

This laboratory is intended for educational and professional development purposes.

All activities are performed in controlled and authorized environments. No unauthorized access, credential collection, malicious infrastructure, or real-world phishing campaign is performed.
