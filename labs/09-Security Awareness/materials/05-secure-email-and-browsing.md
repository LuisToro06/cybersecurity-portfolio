# Secure Email and Web Browsing

## Objective

Promote safe behavior when interacting with email messages, links, attachments, and websites.

## Secure Email Practices

- Verify unexpected messages.
- Inspect the sender.
- Be cautious with attachments.
- Do not provide credentials through unsolicited requests.
- Verify unusual requests using another communication channel.
- Report suspicious messages.

## Safe Web Browsing

- Verify the domain name.
- Inspect suspicious URLs.
- Avoid unexpected downloads.
- Do not enter credentials into suspicious websites.
- Use trusted websites and applications.
- Keep browsers and operating systems updated.

## Key Learning Point

Users should evaluate the context and source of digital requests before interacting with them.
