# Social Engineering Awareness

## Objective

Recognize manipulation techniques that attempt to influence users into performing unsafe actions.

## Common Techniques

- Authority
- Urgency
- Fear
- Trust exploitation
- Impersonation
- Curiosity
- Scarcity

## Controlled Scenario

> "I am from the IT support team. We need your MFA verification code to resolve an urgent account problem."

### Analysis

The scenario contains:

- Authority impersonation
- Urgency
- Request for authentication information

### Recommended Response

The user should not provide the MFA code.

The request should be independently verified and reported according to the applicable security procedure.

## Key Learning Point

Users should verify unusual requests independently instead of relying solely on the apparent identity or urgency of the requester.
