# Multifactor Authentication Awareness

## Objective

Explain the role of multifactor authentication in protecting user accounts.

## Authentication Factors

Common authentication factors include:

1. Something you know
2. Something you have
3. Something you are

## MFA Awareness

MFA adds an additional authentication factor beyond a password.

Users should:

- Enable MFA when available.
- Never approve unexpected authentication requests.
- Never share authentication codes.
- Report suspicious authentication prompts.
- Follow organizational authentication policies.

## Key Learning Point

MFA provides an additional layer of protection when a password is compromised.
