# Phishing Awareness

## 1. Objective

Develop the ability to recognize common phishing indicators and respond appropriately to suspicious messages.

## 2. Controlled Example

### Subject

Urgent Account Verification Required

### Message

> Your account requires immediate verification.
>
> Please verify your account using the link below to avoid service interruption.
>
> [Verify Account]

This message is a fictional educational example created for this laboratory.

## 3. Phishing Indicators

| Indicator | Observation |
|---|---|
| Urgency | The message creates pressure to act immediately |
| Unexpected request | The recipient was not expecting the request |
| Account verification | The message requests an account-related action |
| Call to action | The user is encouraged to interact with a link |
| Potential credential theft | A fraudulent verification page could request credentials |

## 4. Recommended Response

1. Do not click the link.
2. Do not provide credentials.
3. Verify the request using an independent communication channel.
4. Report the suspicious message according to the organization's procedure.
5. Delete the message after appropriate reporting and evidence preservation.

## 5. Key Learning Point

Users should evaluate unexpected messages carefully instead of responding to urgency or pressure.
