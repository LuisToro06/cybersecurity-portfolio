# Information Protection Awareness

## Objective

Promote appropriate handling and protection of information according to its sensitivity.

## Educational Classification

| Classification | Example |
|---|---|
| Public | Public documentation |
| Internal | Internal procedures |
| Confidential | Sensitive organizational information |
| Restricted | Credentials, secrets, authentication material |

## Information Protection Practices

- Share information only with authorized recipients.
- Avoid storing sensitive information in public repositories.
- Protect credentials and authentication secrets.
- Do not expose API keys or tokens.
- Verify recipients before sharing information.
- Follow organizational information handling policies.

## GitHub Security Rule

Never commit credentials, passwords, API keys, access keys, tokens, private keys, MFA codes, or other secrets to a public repository.

## Key Learning Point

Information protection is a shared responsibility and includes appropriate handling, storage, transmission, and disposal.
