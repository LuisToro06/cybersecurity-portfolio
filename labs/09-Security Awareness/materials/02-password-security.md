# Password Security

## Objective

Promote secure authentication practices and reduce risks associated with weak or reused credentials.

## Recommended Practices

- Use long and unique passwords.
- Avoid password reuse between services.
- Use a password manager when appropriate.
- Never share passwords.
- Never store passwords in publicly accessible repositories.
- Change credentials when compromise is suspected.
- Enable multifactor authentication whenever available.

## Credential Protection

Never publish or commit:

- Passwords
- API keys
- Access keys
- Tokens
- MFA codes
- Private keys
- Authentication secrets

## Key Learning Point

Strong authentication practices reduce the likelihood that a compromised password will result in unauthorized access.
