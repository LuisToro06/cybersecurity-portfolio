# Security Awareness Matrix

| Risk Area | Awareness Topic | Learning Objective | Assessment Method |
|---|---|---|---|
| Phishing | Phishing Awareness | Identify common phishing indicators | Knowledge assessment |
| Credential Theft | Password Security | Apply secure password practices | Knowledge assessment |
| Account Compromise | MFA | Understand the role of MFA | Knowledge assessment |
| Social Engineering | Social Engineering | Recognize manipulation techniques | Scenario-based assessment |
| Information Exposure | Information Protection | Identify sensitive information | Scenario-based assessment |
| Malicious Content | Secure Email | Identify suspicious messages and attachments | Knowledge assessment |
| Web Threats | Safe Browsing | Identify suspicious websites and URLs | Scenario-based assessment |
| Security Events | Incident Reporting | Report suspicious activity appropriately | Scenario-based assessment |
