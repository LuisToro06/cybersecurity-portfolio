# Security Awareness Knowledge Assessment

## Instructions

Select the best answer for each question.

This assessment is designed for educational purposes.

---

### Question 1

You receive an unexpected email asking you to verify your account through a link. What should you do?

A. Click the link immediately.  
B. Provide your credentials.  
C. Verify the request using an independent channel.  
D. Forward the email to other users.

**Correct answer:** C

---

### Question 2

What is the primary purpose of MFA?

A. Replace antivirus software.  
B. Add an additional authentication factor.  
C. Encrypt all files.  
D. Block every phishing message.

**Correct answer:** B

---

### Question 3

What should you do with an unexpected suspicious attachment?

A. Open it to determine what it contains.  
B. Forward it to a colleague.  
C. Verify and report it according to security procedures.  
D. Upload it to a public website.

**Correct answer:** C

---

### Question 4

Which is an example of social engineering?

A. Software patching.  
B. Manipulating a person into disclosing information.  
C. Encrypting a database.  
D. Updating a browser.

**Correct answer:** B

---

### Question 5

What should never be published in a public GitHub repository?

A. Public documentation.  
B. A README file.  
C. API keys and passwords.  
D. A cybersecurity article citation.

**Correct answer:** C

---

### Question 6

What should a user do after receiving an unexpected MFA request?

A. Approve it immediately.  
B. Share the code.  
C. Investigate and report the suspicious request.  
D. Disable MFA.

**Correct answer:** C

---

### Question 7

Which behavior is safest when visiting an unfamiliar website?

A. Enter credentials immediately.  
B. Download unknown files.  
C. Verify the domain and context before interacting.  
D. Disable browser security controls.

**Correct answer:** C

---

### Question 8

What is an appropriate response to suspected phishing?

A. Reply to the sender.  
B. Click the link to investigate.  
C. Report the message according to the applicable procedure.  
D. Send credentials to confirm identity.

**Correct answer:** C

---

### Question 9

Why should suspicious cybersecurity events be reported?

A. To increase the number of emails received.  
B. To support timely security analysis and response.  
C. To publicly identify the user.  
D. To disable all user accounts.

**Correct answer:** B

---

### Question 10

What is the purpose of continuous security awareness?

A. Perform one training session and never update it.  
B. Continuously improve knowledge and secure behavior.  
C. Replace all technical security controls.  
D. Eliminate the need for incident response.

**Correct answer:** B
